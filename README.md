# 食物大亂鬥 Food Brawl

食物角色 3D 斜俯視大亂鬥。限時 3 分鐘搶分，一場 8 人，不夠的位子由電腦補上。

- **玩**：https://fyradio.github.io/food-brawl/
- **角色**：蘋果（丟蘋果片／大招滾大蘋果）、壽司（魚卵手裡劍，沒打中留在地上讓人滑倒／大招撒一圈）、茄子（近距離噴汁／大招毒汁水窪）
- **地圖**：沙漠、廚房（每場隨機）
- **連線**：大廳按「開房間」得到 4 位數代碼，朋友按「加入房間」輸入代碼。開房的手機負責算整場，房主離開這場就結束。只有握手需要網路，之後資料在同一個 WiFi 裡直接傳。
- **操作**：手機左搖桿移動、右邊按鈕拉開瞄準放開攻擊（點一下自動瞄準），黃色鈕放大招；電腦 WASD＋滑鼠，右鍵或 E 放大招。

更新方式：改 `/home/claude/foodbrawl.html` 後執行 `gamerelease.py release.json "說明"`（見 fyradio/shoot-arena 的 tools/）。
